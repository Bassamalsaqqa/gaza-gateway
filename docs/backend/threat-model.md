# Phase 12 security and trust-boundary model

Status: Phase 12 Complete / Accepted Source (independently accepted at 7dab821d7d205b41ae925e013fe9c69a97a7e875). No WAF, runtime guard, database or external delivery is claimed to be deployed. Normative security/transaction/publication policies live in the three lifecycle manifests and the exact operation registry.

| Threat / boundary                          | Required mitigation                                                                                                                              | Negative production proof                                                                                                                            |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spoofed passenger/staff identity           | Separate principals, guards, host-only cookies, hashed session lookup, encrypted payload, active/verified/epoch/expiry checks                    | Wrong realm, missing context, suspended/unverified principal, stale epoch, revoked/expired cookie all denied                                         |
| Login/recovery enumeration and brute force | Generic 202 dispatch receipts; DB rate budgets; random purpose-specific proofs, digest storage, atomic consumption                               | Unknown account same observable receipt; budget exhaustion, expired/consumed proof, altered target/email/purpose and session fixation rejected       |
| CSRF or origin bypass                      | Pinned per-operation x-protocol; unconditional raw header comparison; exact Origin; trusted branch selection                                     | Same-origin Sec-Fetch-Site with no header denied; localhost/wildcard origin denied; invalid cookie cannot fall back to guest                         |
| Pending staff or stale MFA privilege       | Purpose/session-bound preauth, current confirmed MFA, one-use counters/codes, staged replacement, fresh session-bound step-up                    | Pending cookie denied on admin/session/me; reused counter/code, foreign version, stale step-up or expired replacement denied                         |
| Last administrator race                    | Singleton sentinel, ascending staff/proof rows, proposed post-state eligibility count for every relevant writer                                  | Two transactions cannot leave zero active verified usable-password confirmed-current-MFA admins                                                      |
| BOLA, PNR guessing and token theft         | Ref is lookup only; decoy-bound email OTP; action/ref/epoch grants; authenticated ownership claim; minimal receipt scope; no localStorage grants | Decoy/undelivered OTP, foreign booking owner, altered ref/action, missing token and revoked-contact epoch denied; receipt exposes no PII             |
| Checkout/price tampering                   | Server session-bound quote/hold/booking/intent; sealed authoritative money/currency/catalog; closed requests                                     | Foreign checkout session, mismatched quote/hold/count/cabin, unsafe minor money or injected paid/price fields denied                                 |
| Seat/capacity races and equipment shrink   | Global service-seat key, complete itinerary service locks, FK-backed allocation, one booking/hold, expiry under locks                            | Competing seats/capacity, opposite leg order, invalid infant seat, orphan adult, expired conversion and incompatible layout fail atomically          |
| Payment spoof/replay/reorder               | Native signature over raw bytes; configured merchant; exact intent/ref/amount/currency; durable unique events/refunds                            | Unsigned/wrong merchant/amount/currency and duplicate events cannot change fulfillment; older failure cannot regress success                         |
| Late settlement or refund fabrication      | compensation_pending with unique refund outbox; no inventory reacquisition; verified full settlement only                                        | Late success never overbooks; request/failed refund never marks cancelled; provider acceptance never masquerades as settlement                       |
| CMS XSS/style injection                    | Typed localized docs, key binding/revisions, bounded authentic appearance tokens/targets, sanitizer/CSP at rendering                             | Unknown CSS/script/cards/token/target, wrong document kind, stale revision, dangerous URL or unsafe rich content rejected                            |
| Malicious media/SSRF                       | MIME/size/decoder validation, private originals, allowlisted immutable derivatives; fetch only fixed accepted origins                            | Executable/polyglot upload, traversal, symlink, arbitrary external URL and internal-network fetch denied                                             |
| Historical truth/rights fabrication        | Preserve source enums/basis/rights/uncertainty, intake hold-provenance, NULL unasserted source status; target media policy                       | AI future concept never classified as Past/Present documentary proof; owner-directed display never upgrades legal rights/evidence                    |
| Mutable or forged static publication       | Immutable snapshot hashes, exact release pins, ordered artifact hashes, owner+server verified receipt, step-up/CAS pointer                       | Missing/unknown pin, live draft read, altered snapshot/file, mismatched receipt, false probe or stale activation denied                              |
| Staging reaching production                | Separate workspaces/DB/queues/buckets/secrets, closed DB external ingress, exact API hosts/origins                                               | Staging credentials/network/processes cannot read prod DB, dispatch prod mail/payment or activate prod snapshot                                      |
| PII/secret/audit leakage                   | Encrypted documents/outcomes/dispatch, minimal public receipts, no-store, bounded redacted logs, append-only audit role                          | Password/token/OTP/card/document/contact body absent in logs/static artifact/public receipt; audit UPDATE/DELETE denied                              |
| Recovery/data migration tampering          | Consent-bound authenticated preview/commit, genuine clean seeds, backups/restore drills and owner cutover                                        | Prototype credentials/bookings/overrides/fake audit rejected; replayed consent or foreign preview denied; restore reconciles inventory/payment state |

Residual risks require live evidence in Phase 13: exact provider signature semantics, delivery status, real concurrency and FK enforcement, native PHP hashing/session handlers, proxy header chain, artifact probes, backups, key recovery and restore times. Deterministic models explicitly use synthetic verified crypto/provider/probe outcomes where no external system exists. They must not be used as production adapters.

Initial paid service budget, region/residency, merchant eligibility, legal retention and irreversible production cutover remain owner decisions. No real airline/GDS feed or live airport operating status is invented.

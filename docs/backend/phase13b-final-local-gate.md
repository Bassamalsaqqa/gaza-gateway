If Composer dependencies are installed in a different isolated worktree, supply its absolute `backend/vendor` path in `IDENTITY_GATE_VENDOR`; the gate checks the installed platform and Composer metadata. Random local APP_KEY/OTP pepper values remain in process/container memory; no credentials are emitted in the receipt. Cleanup removes only those exact run-owned resources.

The migration test now includes the later cleanup-index migration and requires the disposable-instance flag; it cannot silently roll back the retained database's identity/audit tables.

`backend/tests/identity-final.xml` registers every Feature/Identity* and Unit/Identity* directory, including the original security primitive, maintenance, proof, profile and abuse-review suites. The gate fails if an identity directory is omitted. MigrationLifecycleTest runs separately before fixtures to preserve its destructive isolation boundary. This is the complete identity-only suite, not the entire frontend/backend regression suite. It includes actual-kernel lifecycle chains and independently generated separate-process races. Optional capture instrumentation records the first genuine successful response per closed identity operation, with no request bodies/cookies/headers. Its private exclusive directory is deleted after validation. All 46 operation successes must validate against their actual OpenAPI status/media schema; canonical false-success tampering must fail. The gate also checks generated client parity, backend contracts and the affected identity client/UI boundary tests.

Logs and a secret-free SHA-256 receipt remain under `scratch/gaza_identity_gate_<run>/`. The receipt pins a clean committed Git head, source hashes, commands, exit codes, migrations, response artifact hashes and test summaries. A failed PHP suite preserves JUnit before owned-container teardown and produces no passing receipt. Preserve failures; after a correction rerun only the affected checks and distinguish cumulative evidence from a single green run. Final acceptance requires an unfiltered passing gate at the resulting exact candidate SHA.

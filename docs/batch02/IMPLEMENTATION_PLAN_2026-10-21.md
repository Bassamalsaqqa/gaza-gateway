## Architecture

- Preserve the React/TanStack public client, Laravel/MySQL authority, HostPapa SMTP and bounded existing dispatcher. No new production Node service.
- Ticket: use the exact owner-supplied 1774×887 PNG and native-coordinate field overlay. This newly approved 2:1 design supersedes the earlier 8×3.25-inch composition. One ticket per saved passenger per flight leg, accessible booking summary and authenticated access unchanged. Client PNG and A4 print are first-class; server email artwork requires verified multilingual rendering, not browser code embedded in email.
- Booking: retain current name/email-first guest contract, optional details, 12-hour email proof/recovery, ten-attempt limit, idempotency and atomic round trips. Refactor presentation into guided sections and an accessible OTP dialog without weakening server validation.
- Destinations: add Oslo/OSL and Stockholm/ARN with optimized supplied photography, bilingual registries and additive database admission/reference/schedule changes. Preserve existing published records and local timezone semantics.
- Contributions: save bounded, validated submissions and original assets privately. Staff-authorized review/download only; no automatic public publication. Record consent and issue a server-generated public reference. Use the existing SMTP safety model for admin notification and personalized thank-you artwork. Optional CC applies only to incoming submission notifications.
- Travel: preserve deep links/history while preventing tab navigation from resetting scroll. Use solid brand surfaces. The transport explorer is explicitly a heritage-inspired concept, not a current service or timetable. Historical inspiration: https://www.palestineremembered.com/tags/Transportation-Co..html .

## Work and review

AGY receives bounded, isolated tasks for ticket, booking, destinations, archive/email settings and travel. Codex reviews actual changes, resolves shared contracts and independently runs focused gates. No worker may commit, push, modify other worktrees, deploy or access credentials/backups.

The Google Worker controller preparation stalled before creating its first worktree in this Windows environment; its owned process was stopped. Equivalent isolated linked Git worktrees and the installed AGY relay are used, with before/after HEAD, index and changed-file inspection retained manually. No worker self-report substitutes for integration review.

## Acceptance gates

Focused booking retry/round-trip/OTP regression, ticket data/render/export checks, archive upload/private access/mail routing checks, and network/schedule admission checks. One integrated typecheck and scoped lint, then a local build and EN/AR browser screenshots of the affected experiences. Disposable local databases/capture mail only. No broad redundant suites or GitHub Actions.

Do not merge, deploy or prepare a production ZIP in this implementation mission. Preserve original production execution/incident records. Cleanup begins with an inventory; owner-supplied assets, unrelated checkout changes, backups and forensic evidence remain protected.

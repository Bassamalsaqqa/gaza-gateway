3. **Routing, Locales & Directionality**:
   - Route files are flat under `src/routes/` using TanStack dot-notation.
   - Public routes use the optional segment prefix `src/routes/{-$locale}.*.tsx` serving `/` (English, LTR) and `/ar` (Arabic, RTL).
   - Admin routes use `src/routes/{-$locale}.admin.*.tsx` (or `{-$locale}.admin_.signin.tsx` for layout bypass) serving `/admin/*` and `/ar/admin/*`.
   - Never combine EN and AR strings into a single UI label (e.g. no "Flights / رحلات"). Always render separate strings via `useI18n()` / `t()`.
   - Technical identifiers must remain LTR: flight numbers (`PS 204`), booking references / PNRs (`GZA-7K8P`), IATA codes (`GZA`, `AMM`), ISO dates (`2026-09-18`), times (`14:30`), phone numbers, and emails.
